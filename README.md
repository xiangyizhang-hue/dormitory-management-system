# 学生宿舍数据库管理系统

这是我的数据库课程设计项目，使用 Python、PyQt5 和 MySQL 做一个单机桌面管理系统。我希望把“学生入住、退宿、床位数量同步变化”这一业务过程落到具体的数据约束和事务中，而不只是做增删改查界面。

## 我做了什么

- 建立学生、宿舍、入住分配、报修四张表，使用主键、外键、唯一约束维护基础数据关系。
- 完成学生、宿舍和入住分配三个桌面管理页面；界面查询使用参数化 SQL。
- 将入住和退宿写入事务服务：同时更新分配记录与剩余床位；分配时锁定宿舍行，并检查可用床位，避免重复占用。
- 把数据库连接信息改为环境变量配置，没有把个人密码写在源码中；为分配和退宿逻辑加入不依赖真实数据库的单元测试。

这个项目让我更具体地理解了“数据一致性”：一项业务操作如果需要修改多张表，就要考虑其中一步失败后如何回滚，而不是让界面显示成功、数据库却只更新一半。

## 运行与测试

需要 MySQL 8、Python 3.10 或更新版本。

```bash
pip install -r requirements.txt
```

参照 `.env.example` 设置 `DORM_DB_*` 环境变量后，运行：

```bash
python init_dorm_db.py
python dorm_manage_gui.py
```

不启动 MySQL 也能运行事务逻辑的单元测试：

```bash
python -m unittest discover -s tests -v
```
